# PTE 52 Lab Plus · 151 题扩充题库

一个纯静态的 PTE 练习网站：**151 道题、19 种题型**，做完立即给答案、解析和 52 分策略提示。第 2 课 PPT 里的 38 句 RS 和 40 题 ASQ 已全部收录。

## 怎么打开

**方式一（最简单）**：双击 `index.html`，用 Chrome 或 Edge 打开。

**方式二（推荐，录音权限更稳定）**：

```bash
cd pte-site
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 有什么

- **8 天路线**：每天 4 题，按 RA → RS/ASQ → DI/RTS → SWT/WE → FIB → RO/MCQ → WFD/SST → FIB-L/HIW 排列。
- **第 2 课专区**：首页“第 2 课 · RS + ASQ”一键练 PPT 里的 38 句 RS + 40 题 ASQ。
- **19 种题型**：朗读、复述、描述图片、情景应答、简答、一句话概括、大作文、阅读填空、拖拽填空、排序、单选、多选、听力摘要、听写、点错词、听力填空、听力选择、选摘要、选缺失词。
- **即时反馈**：选择题自动判分并标出正确项；听写逐词标红；RO 按相邻对给分。
- **口语/写作**：计时 + 录音（需麦克风权限）+ 示范答案 + 自查清单，自评后记入进度。
- **进度**：按题型统计正确率、连续天数，数据只存在浏览器本地。

## 说明

- 所有题目按官方题型自编，**不是真题原文**；正式备考请配合官方练习题。
- 听力音频使用浏览器语音合成（SpeechSynthesis），建议 Chrome / Edge。
- 录音只保存在本地浏览器，不会上传。
- 题库在 `assets/questions.js`，按同样格式追加即可。


## 模考

- 入口：顶部「模考」。
- **完整版（1 套）**：阅读 14 题 / 29 分钟 + 听力 17 题 / 35 分钟，共 31 题，按真实考试题量组卷（听力含 1 题 SST 自评，不计入估分）。
- **迷你卷（3 套）**：A/B/C，每套 12 题（阅读 6 + 听力 6），每节 15 分钟，用于日常。
- 规则：不可回看、每节独立计时、时间到自动交卷、交卷前不显示对错。
- 交卷后：给出阅读/听力估分（10 + 正确率 × 80）、总分，以及逐题「你的答案 / 正确答案 / 解析 / 52 分提示」。
- 记录保存在浏览器本地，可随时回看解析。

> 模考题按官方题型自编，不是真题原文；估分只用于练习定位，不是官方 PTE 成绩。
